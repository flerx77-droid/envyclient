# EnvyClient — сайт клиента

Лендинг для скачивания и продвижения EnvyClient (Minecraft 1.21.4).
Стиль вдохновлён сайтами популярных майнкрафт-читов: тёмная тема,
неоновый акцент, hero-блок со скачиванием, модули, установка и FAQ.

## Структура

```
EnvyClient-site/
├── index.html      — главная страница (одностраничник)
├── css/style.css   — все стили
├── js/main.js      — звёзды, анимации, FAQ-аккордеон, навигация
├── img/            — скриншоты клиента
│   └── menu.png    — меню при первом входе (на hero и в галерее)
├── files/          — сюда кладём jar для скачивания
│   └── README.txt  — инструкция, что сюда положить
└── README.md
```

## Как запустить

Просто открой `index.html` в браузере (двойной клик). Сайт работает
локально без сервера.

## Куда загрузить, чтобы было доступно всем

Чтобы люди могли скачивать, выложи содержимое папки на любой хостинг
статики, например:

- **GitHub Pages** — создай репозиторий, положи файлы, включи Pages (бесплатно).
- **Vercel / Netlify** — перетащи папку в интерфейс (бесплатно).
- **Любой другой статик-хостинг** — скопируй файлы.

## Важно: файл для скачивания

Кнопки «Скачать» ведут на установщик в GitHub Releases:

`https://github.com/flerx77-droid/envyclient/releases/download/v1.0.0/EnvyClient-Setup-1.0.0.exe`

Чтобы выпустить новую версию — собери лаунчер (`launcher`, `npm run dist`), залей
exe в новый релиз на GitHub (новый тег), кнопка на сайте продолжит работать,
если использовать ссылку вида `.../releases/latest/download/...`.

## Как поменять

- **Цвета / шрифты** — в начале `css/style.css` (переменные `:root`).
- **Тексты, модули, FAQ** — прямо в `index.html`.
- **Скриншоты** — новые картинки клади в `img/` (например `menu2.png`) и добавь их в галерею в секции `#screenshots` в `index.html`.
- **Ссылка на Discord** — замени пустые ссылки `href="#"` на свой
  инвайт в `index.html` (в hero, навбаре и футере).

## Статус «альфа»

На сайте добавлен баннер и вопрос в FAQ о том, что клиент в альфа-тестировании:
возможны недоделки, античиты могут жаловаться, и автор ответственности за баны
не несёт. Если хочешь убрать/изменить текст — найди блок `<section class="notice-wrap">`
в `index.html`.
